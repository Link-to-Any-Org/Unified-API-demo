# Security policy

This is a demo application. Before using it against anything but a disposable
test/sandbox account, read the warning in the [README](README.md) -
the order/payment flow writes real, immediately captured payments against
whatever account is connected.

## Reporting a vulnerability

If you find a security issue in this repository (not in a connected
provider or the LinkToAny Unified API themselves), please open a private report via GitHub's
"Report a vulnerability" feature on this repo's Security tab, rather than a
public issue. Include steps to reproduce and the potential impact.

Issues with a connected provider's platform or the LinkToAny Unified API should
go to those vendors directly, not this repository.
